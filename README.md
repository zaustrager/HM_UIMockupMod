This mod is cloned from Atampy26’s Simple Mod Framework Mod Template and dbierk’s HitmanCampaignDemo but has been modified to be more for mockups of fictional missions/targets rather than actual playing levels. This also includes a visual editor tool where you can modify the variables within a no-code interface.

To use this mod, you must have the following items:
<ul>
  <li> HITMAN: World of Assassination (EGS/Steam) Version 3.260.1 or above. </li>
  <li> Simple Mod Framework 2.33.35 </li>
  <li> The Peacock Project Server 8.7.0 </li>
</ul>

In the editor.html file, where you can make direct changes, you **must** make sure you choose the correct mod folder on the top, or else the changes won't apply.

Put the "UIUX.plugin.js" file in the plugins folder where your Peacock instance is hosted on your local device.

The modded mission can be accessible via Campaigns > Modded Levels and is the second mission in the campaign.
